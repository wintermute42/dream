# Security

Dream runs on your own Mac and, with `--lan`, in your home network; guests on the phone remote get a key with limited
rights, Dream Control a key with all rights (see the README, "Phone remote"). If you find a way around that – a guest
doing what only Dream Control may do, a web page steering Dream, a key leaking, the cloud GPU starting without consent –
please **report it privately**: on GitHub, *Security → Report a vulnerability*
(https://github.com/wintermute42/dream/security/advisories/new). Please do not open a public issue for it.

You will get an answer as soon as possible; a fix comes first, then the advisory is published together with it.
